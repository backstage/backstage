# @backstage/cli-module-package-manager-patch

CLI module that provides patch generation for other repositories commands for the Backstage repo tools CLI.

## Commands

| Command                    | Description                                                        |
| :------------------------- | :----------------------------------------------------------------- |
| `generate-patch <package>` | Generate a patch for the selected package in the target repository |
