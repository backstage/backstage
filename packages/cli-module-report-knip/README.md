# @backstage/cli-module-report-knip

CLI module that provides knip report generation commands for the Backstage repo tools CLI.

## Commands

| Command                   | Description                                  |
| :------------------------ | :------------------------------------------- |
| `knip-reports [paths...]` | Generate a knip report for selected packages |
