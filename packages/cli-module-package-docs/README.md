# @backstage/cli-module-package-docs

CLI module that provides experimental package documentation generation commands for the Backstage repo tools CLI.

## Commands

| Command                   | Description                                                            |
| :------------------------ | :--------------------------------------------------------------------- |
| `package-docs [paths...]` | Generate package documentation (experimental, hidden from help output) |
