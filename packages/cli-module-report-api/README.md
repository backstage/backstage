# @backstage/cli-module-report-api

CLI module that provides API, CLI and SQL report generation commands for the Backstage repo tools CLI.

## Commands

| Command                  | Description                                             |
| :----------------------- | :------------------------------------------------------ |
| `api-reports [paths...]` | Generate API, CLI and SQL reports for selected packages |
