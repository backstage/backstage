# @backstage/cli-module-repo-checks

CLI module that provides dependency and catalog metadata checks commands for the Backstage repo tools CLI.

## Commands

| Command                                  | Description                                                       |
| :--------------------------------------- | :---------------------------------------------------------------- |
| `type-deps`                              | Find inconsistencies in types of all packages and plugins         |
| `peer-deps`                              | Ensure your packages are using the correct peer dependency format |
| `generate-catalog-info`                  | Create or fix info yaml files for all backstage packages          |
| `lint legacy-backend-exports [paths...]` | Lint backend plugin packages for legacy exports                   |
