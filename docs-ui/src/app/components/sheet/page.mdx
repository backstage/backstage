## API reference

### SheetTrigger

Wraps a trigger element and the sheet content to handle open and close state.

<PropsTable data={sheetTriggerPropDefs} />

<ReactAriaLink component="SheetTrigger" href={reactAriaUrls.sheetTrigger} />

### Sheet

The sheet panel and overlay. Supports controlled open state, logical start and end positions, snap points, and swipe dismissal.

<PropsTable data={sheetPropDefs} />

<ReactAriaLink component="Sheet" href={reactAriaUrls.sheet} />

### SheetHeader

Displays the sheet title with a built-in close button.

<PropsTable data={sheetHeaderPropDefs} />

<ReactAriaLink
  component="Heading"
  href="https://react-aria.adobe.com/Heading"

### SheetBody

The main content area of the sheet.

<PropsTable data={sheetBodyPropDefs} />

### SheetFooter

Contains action buttons or other footer content.

<PropsTable data={sheetFooterPropDefs} />

If you want to close the sheet when pressing a button, use the `slot="close"` prop on the button.

## Examples

### Positions

Use the `position` prop to choose which edge of the viewport the sheet opens from. The `start` and `end` positions are mirrored in right-to-left layouts.

  align="center"
