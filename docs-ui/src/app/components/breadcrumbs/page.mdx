## Examples

### Truncation

Non-current segments are capped at a max width. Overflowing text is truncated with an ellipsis. When a segment is truncated, a tooltip showing the full text appears on hover or focus. Truncation state updates automatically on window resize, so tooltips appear or disappear as segments overflow. The current (last) segment has no max width — but if its container is constrained, it can still truncate and will also show a tooltip.

<Snippet
  align="center"
  py={4}
  preview={<Truncation />}
  code={truncationSnippet}
/>

### Collapsed

When there are 5 or more segments, the middle items automatically collapse into an ellipsis menu. The first segment and the last two segments stay visible. Clicking the ellipsis button opens a menu with the hidden segments.

  align="center"

/>

### Inherits style

Breadcrumbs inherit font size and color from their parent, including the chevron separator which scales with the text.

Breadcrumbs can mix linked and plain-text segments. Segments without an `href` render as static text.
