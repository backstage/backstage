## Examples

### Truncation

Non-current segments are capped at a max width. Overflowing text is truncated with an ellipsis. When a segment is truncated, a tooltip showing the full text appears on hover or focus. Truncation state updates automatically on window resize, so tooltips appear or disappear as segments overflow. The current (last) segment has no max width — but if its container is constrained, it can still truncate and will also show a tooltip.

/>

### Collapsed

When there are 5 or more segments, the middle items automatically collapse into an ellipsis menu. The first segment, one leading segment, and the current page stay visible. Clicking the ellipsis button opens a menu with the hidden segments.

### Variant and colour

Set `variant`, `color`, and `weight` on `Breadcrumbs` to style all segments. Individual `Breadcrumb` items can override these props.

### Mixed segments

Breadcrumbs can mix linked and plain-text segments. Segments without an `href` render as static text.

## Customisation

Typography (variant, colour, weight) is controlled via the `variant`, `color`, and `weight` props on `Breadcrumbs` and `Breadcrumb`. The separator can be replaced via the `separator` prop. Layout tokens below can be passed via the `style` prop on `Breadcrumbs` or set on a parent element.
