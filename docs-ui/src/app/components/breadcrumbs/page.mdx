## Examples

### Truncation

Non-current segments are capped at a max width. Overflowing text is truncated with an ellipsis. When a segment is truncated, a tooltip showing the full text appears on hover or focus. The current (last) segment has no max width and is displayed in bold — but if its container is constrained, it can still truncate and will also show a tooltip.

  align="center"
  py={4}
  preview={<Truncation />}
  code={truncationSnippet}
/>

### Inherits style

Breadcrumbs inherit font size and color from their parent, including the chevron separator which scales with the text.

Breadcrumbs can mix linked and plain-text segments. Segments without an `href` render as static text.
