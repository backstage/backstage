API reports, SQL reports and the code generated by `package schema openapi generate` are now formatted with `backstage-cli package format`, which uses whichever formatter module your project has installed, such as Prettier or oxfmt. All reports are formatted in a single batch, including reports that the ignore file of your formatter lists. If no installed CLI module provides the format command, formatting is skipped with a message. This needs a version of `@backstage/cli` that provides `package format` with the `--include-ignored` option. When a report is out of date in `--ci` mode, the changes for all out-of-date reports are now listed before the command fails.
