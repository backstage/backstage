'@backstage/ai-node': minor
---

Added a new `@backstage/ai-node` package with an alpha, plugin-scoped AI service that gives backend plugins a managed, low-level agent primitive: each plugin chooses its own configuration path in app-config, sessions are bound to their original owner, and callers acquire reference-counted handles whose release never cancels admitted work. Model dispatch is guarded per attempt — permission, lease fencing, and credential identity are rechecked before any provider request, and every decision and outcome is recorded in a durable, redacted audit journal. Provider credentials and the model catalog are not yet configurable, so model requests fail closed with an actionable reason until an installation supplies them. Plugins can persist agent sessions in their existing PostgreSQL or file-backed SQLite database and recover committed state after a backend restart, with fenced writes that prevent expired or superseded owners from changing a session. Organization- and service-scoped provider credentials can be supplied as read-only secrets from app-config, and users can store personal provider credentials encrypted in the Backstage database, with concurrent updates and OAuth refreshes serialized across replicas.
