Frontend plugins that are built as module federation remotes, with `package build --module-federation` or `package bundle`, now get a `backstage-manifest.json` file next to `mf-manifest.json`. The file is also written to the `dist` folder of frontend plugin and module packages by `package prepack`, so that published packages include it. It describes each exposed plugin in its `frontend` section, and whether the plugin can be deferred, which lets an app load the plugin on demand. Whether a plugin can be deferred is decided by reading the type declarations that `yarn tsc` emits to `dist-types`, so they must exist when the package is built or packed, and the reason a plugin can't be deferred is recorded in the file.

A plugin can be deferred only if each of its extensions is a page or sub-page made with `PageBlueprint` or `SubPageBlueprint`, or a utility API made with `ApiBlueprint`, all from `@backstage/frontend-plugin-api`. The `path` and `title` params of a page or sub-page must be literal values. A `routeRef` must be one of the routes of the plugin, and be created with `createRouteRef({ id })` so that it can be matched with the routes. A page whose route ref has no ID is assumed to use the `root` route of the plugin, and a sub-page must have one. Params that are only used to create the element, such as `loader`, can be anything. Extensions made with any other blueprint, including the entity card and entity content blueprints, or with `makeWithOverrides`, and params that are not literal values, such as an `icon`, prevent the plugin from being deferred. The stand-ins of pages and sub-pages apply their `path` and `title` config from `app.extensions`, and other config for an element of a deferred plugin loads the plugin right after the app has started. Utility APIs made with `ApiBlueprint` are recorded in the manifest, so that they can be loaded on first use. Their API ref must be declared as a promise, such as with `createApiRef<Promise<MyApi>>()`, since a deferred plugin provides its APIs as promises until it is loaded, otherwise the plugin is not deferred.
