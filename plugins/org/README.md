# @backstage/plugin-org

The `org` plugin provides views and components for organization data in the Software Catalog, such as user profiles, group pages, and team membership cards.

## Installation

```shell
yarn --cwd packages/app add @backstage/plugin-org
```

## Documentation

See the [Backstage documentation](https://backstage.io/docs/features/software-catalog/org) for setup, configuration, and customization details.
