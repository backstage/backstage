# @backstage/plugin-techdocs-module-addons-contrib

This package contains [TechDocs Addons](https://backstage.io/docs/features/techdocs/addons) for customizing TechDocs documentation pages. It includes the following addons:

- `<ExpandableNavigation />` - Expand or collapse the TechDocs main navigation
- `<ReportIssue />` - Select text to open a pre-filled issue against the documentation source repository
- `<TextSize />` - Adjust the font size on documentation pages
- `<LightBox />` - Click on images to open them in a light box

## Getting Started

See the [TechDocs Addons documentation](https://backstage.io/docs/features/techdocs/addons) for installation and usage instructions.
