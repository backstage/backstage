# @backstage/plugin-catalog-import

The `catalog-import` plugin provides a wizard to onboard repositories and register entity descriptor files into the Software Catalog.

## Installation

```shell
yarn --cwd packages/app add @backstage/plugin-catalog-import
```

## Documentation

See the [Backstage documentation](https://backstage.io/docs/features/software-catalog/catalog-import) for configuration, customization, and usage instructions.
