# Scaffolder React

This is shared code of the frontend part of the default Scaffolder plugin.

It will implement the core API for working with the Scaffolder, and
supplies components that can be reused by third-party plugins.

## BUI form theme

With `formProps={{ EXPERIMENTAL_theme: 'bui' }}`, nested object parameters display
their `title` and `description` above their fields. Array items use their card
headers instead; objects nested inside an array item still display their own
titles and descriptions.
