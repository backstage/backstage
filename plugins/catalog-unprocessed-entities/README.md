# @backstage/plugin-catalog-unprocessed-entities

The `catalog-unprocessed-entities` plugin provides a frontend interface to inspect entities that failed processing or remain pending during catalog ingestion.

## Installation

```shell
yarn --cwd packages/app add @backstage/plugin-catalog-unprocessed-entities
```

## Documentation

See the [Backstage documentation](https://backstage.io/docs/features/software-catalog/unprocessed-entities) for setup, configuration, and usage instructions.
