# @backstage/plugin-catalog-graph

The `catalog-graph` plugin visualizes relations between entities in the Software Catalog, including ownership, dependencies, and system groupings.

## Installation

```shell
yarn --cwd packages/app add @backstage/plugin-catalog-graph
```

## Documentation

See the [Backstage documentation](https://backstage.io/docs/features/software-catalog/catalog-graph) for setup, configuration, and customization options.
