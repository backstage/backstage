# events-backend-module-gitlab

This module routes GitLab events to event-specific topics in the Backstage events backend and provides token validation for GitLab webhooks.

## Installation

```bash
# From your Backstage root directory
yarn --cwd packages/backend add @backstage/plugin-events-backend-module-gitlab
```

## Documentation

See [GitLab Events](https://backstage.io/docs/integrations/gitlab/events) for backend setup, token validator configuration, and routing details.
