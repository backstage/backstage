# @backstage/plugin-scaffolder-backend-module-github

The github module for [@backstage/plugin-scaffolder-backend](https://www.npmjs.com/package/@backstage/plugin-scaffolder-backend).

_This plugin was created through the Backstage CLI_

## Actions

- `publish:github`
- `publish:github:pull-request`
- `github:actions:dispatch`
- `github:autolinks:create`
- `github:branch-protection:create`
- `github:deployKey:create`
- `github:environment:create`
- `github:issues:create`
- `github:issues:label`
- `github:pages:enable`
- `github:repo:create`
- `github:repo:push`
- `github:repo:rulesets:create`
- `github:webhook`

Each action's inputs and examples are listed in your Backstage instance at `/create/actions`.
