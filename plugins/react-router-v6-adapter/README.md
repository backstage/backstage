# @backstage/plugin-react-router-v6-adapter

> **Tombstone / private package.** Do not depend on this package.
>
> The React Router v6 default page router now lives in `@backstage/plugin-app`
> at `plugins/app/src/routing/reactRouterV6` and is registered as the app's
> silent default via `pageRouterApiRef` (RFC
> [#33603](https://github.com/backstage/backstage/issues/33603)).
>
> This package exports nothing and exists only so the workspace path can be
> removed cleanly in a follow-up.
