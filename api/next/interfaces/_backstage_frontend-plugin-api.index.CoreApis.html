    Readonlyfetch

    fetch: ApiRef<FetchApi, "core.fetch"> & { $$type: "@backstage/ApiRef" }

    The ApiRef of FetchApi.

    Remarks

    This is a wrapper for the fetch API, that has additional behaviors such as the ability to automatically inject auth information where necessary.

    Note that the default behavior of this API (unless overridden by your org), is to require that the user is already signed in so that it has auth information to inject. Therefore, using the default implementation of this utility API e.g. on the SignInPage or similar, would cause issues. In special circumstances like those, you can use the regular system fetch instead.

    Readonlyinternal

    internal: InternalCoreApis

    References to core Utility APIs primarily intended for framework integrations.

    Remarks

    These APIs support app initialization, OAuth request coordination, and rendering infrastructure. Most plugins should use higher-level abstractions such as PluginWrapperBlueprint, PluginHeaderActionBlueprint, and createSwappableComponent. These refs are public exports for integrations that need direct access.
