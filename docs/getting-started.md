# Getting Started

## Navigating the Portal

### Home Page

The home page shows a welcome screen with quick access to the software catalog and search.

### Software Catalog

Click **Catalog** in the sidebar to browse all registered components. You can filter by:

- **Kind** — Component, System, Group, API
- **Type** — website, library, service
- **Owner** — blitzy-sandbox
- **Tags** — typescript, rust, python, go, etc.

### Viewing a Project

Click any component to see its detail page:

- **Overview** — Description, metadata, links to GitHub
- **TechDocs** — Auto-generated documentation (if the repo has `mkdocs.yml`)
- **Dependencies** — Related systems and APIs

### Search

Use the search bar (or press `/`) to search across all catalog entities and documentation.

## Authentication

The portal supports two sign-in methods:

1. **GitHub OAuth** — Sign in with your GitHub account for full access
2. **Guest access** — Browse the catalog without signing in (read-only)
