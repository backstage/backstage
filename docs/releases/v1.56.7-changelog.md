# Release v1.56.7

Upgrade Helper: [https://backstage.github.io/upgrade-helper/?to=1.56.7](https://backstage.github.io/upgrade-helper/?to=1.56.7)

## @backstage/backend-defaults@0.18.2

### Patch Changes

- bd906a0: Azure Blob Storage URLs are now matched against integrations by exact account host, so an integration no longer claims URLs of a storage account whose name merely ends with the configured account name.
- 55408d1: The Gerrit and Bitbucket Cloud URL readers now derive the base of their request URLs from the parsed URL rather than from the raw URL string.
- bdf83d7: The GitHub and Bitbucket URL readers now reject URLs whose repository, owner, or reference parts contain path traversal or URL query and fragment delimiter sequences, including in their default branch and commit lookups.

## @backstage/plugin-auth-backend@0.30.3

### Patch Changes

- c0eec19: Made matching of the `allowedRedirectUriPatterns` and `allowedClientIdPatterns` configuration case-sensitive for URL paths, while the host part of a URL stays case-insensitive as required by URL semantics. Redirect URIs and client IDs that differ from a configured pattern only by path casing are now rejected. Wildcards keep working, including in the path, but the literal text of a pattern is matched case-sensitively too, so a pattern such as `https://app.example.com/oauth/*` no longer matches `https://app.example.com/OAUTH/...`.

## @backstage/plugin-scaffolder-node@0.13.9

### Patch Changes

- e0b5d8e: The `fetchContents` helper used behind `fetch:plain` and `fetch:template` now rejects fetched trees that contain a `.git` directory, matched case-insensitively. The repository initialization used by scaffolder publish actions now replaces any pre-existing `.git` directory in the source path instead of reusing it.
