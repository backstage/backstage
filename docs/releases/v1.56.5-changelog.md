# Release v1.56.5

Upgrade Helper: [https://backstage.github.io/upgrade-helper/?to=1.56.5](https://backstage.github.io/upgrade-helper/?to=1.56.5)

## @techdocs/cli@1.14.1

### Patch Changes

- f8a717e: Restricts `markdown_extensions` in `mkdocs.yml` to known extension names before documentation generation, in both the MkDocs and Zensical engines. Extension names outside the permitted set are removed from the configuration with a warning. Allow additional extensions, for example from a custom build image, with the new `techdocs.generator.mkdocs.dangerouslyAllowAdditionalExtensions` configuration, or the `--dangerouslyAllowAdditionalExtensions` flag when using the TechDocs CLI.
- Updated dependencies
  - @backstage/plugin-techdocs-node@2.2.1

## @backstage/plugin-catalog-backend-module-gitlab@0.8.10

### Patch Changes

- 700a199: GitLab discovery entity provider: catalog locations and refresh keys resulting from push events are now derived from the project record fetched from the GitLab API, instead of fields of the event payload. Committed file paths that do not resolve within the project itself are ignored.

## @backstage/plugin-scaffolder-backend@4.2.2

### Patch Changes

- bce6b93: Fixed matching of action input values in scaffolder permission policies, including identifiers that are provided either as numbers or as strings.
