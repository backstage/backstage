# Create App Golden Path author guidance

## Goal

This Golden Path is a learning-oriented tutorial for developers and
administrators who are new to Backstage. It starts with no Backstage project and
ends with an unchanged app generated by `@backstage/create-app` running locally.
The reader should understand the stock portal and know where its configuration,
frontend, backend, and example data live.

The tutorial must stay aligned with
`packages/create-app/templates/default-app`. Treat the generated template as the
source of truth for installed packages, configuration, files, example data, and
visible features.

## Scope

The tutorial has four sequential steps:

1. Scaffold the app.
1. Run it locally.
1. Explore the portal.
1. Understand the project.

Do not add customization tasks to this tutorial. Plugin installation,
authentication configuration, theming, upgrades, deployment, and organizational
adoption belong in their dedicated how-to guides or Golden Paths. Link to those
documents from the completion page instead.

## Writing guidelines

- Write each page as one part of a single beginner tutorial.
- Give the reader concrete actions and an observable result.
- Use the current generated app as the baseline; do not ask readers to install
  or configure template defaults.
- Keep architecture explanations brief and connect them to files the reader has
  generated.
- Use Node.js Active Long Term Support requirements rather than pinning a Node.js
  or Yarn version that will become stale.
- End each page with a direct link to the next step.
