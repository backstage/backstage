Backstage provides common libraries that you can use in frontend and backend
code. These guides explain how to use their shared types, utilities, and
conventions when building applications and plugins.

- [Error handling](./errors.md): Choose error types, add context, and recognize
  errors across package copies and service boundaries with `@backstage/errors`.

For individual API signatures, see the [API reference](https://backstage.io/api/stable).
